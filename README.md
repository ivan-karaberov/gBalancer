# HTTP Балансировщик Нагрузки на Go

Этот проект представляет собой простой HTTP балансировщик нагрузки, реализованный на языке Go. Он принимает входящие HTTP-запросы и распределяет их по пулу бэкенд-серверов с использованием алгоритма (round-robin/random). Также реализован модуль ограничения частоты запросов (rate-limiting) на основе алгоритма Token Bucket.

## Функциональные возможности

Load Balancer
- Принимает и обрабатывает входящие HTTP-запросы на заданном порту
- Запросы распределяются на заранее заданные бэкенд-серверы (по алгоритму Round-Robin/Random).
- Проверяет доступность бэкендов (HealthCheсk)
- Поддерживает конфигурацию через JSON файл.
- Обработывает нескольких запросов одновременно с использованием горутин.

Rate Limiting
- Реализует алгоритм Token Bucket для ограничения частоты запросов
- Поддерживает индивидуальные настройки лимитов для каждого клиента
- Автоматически пополняет токены с заданной периодичностью
- Предоставляет API для управления клиентами (создание, получение, обновление, удаление)


## Установка и запуск
1. Клонируйте репозиторий:
```bash
git clone git@github.com:ivan-karaberov/gBalancer
cd gBalancer
```

2. Установите зависимости:
```bash
go mod tidy
```

3. Заполните `.env` файл:

4. Запустите сервер:
```bash
go run main.go
```

## Конфигурация
Конфигурация балансировщика и rate limiter загружается из файла config.json. Пример:
```json
{
"port" : 8080,
"backends": [
  "http://localhost:3000",
  "http://localhost:4001"
],
"capacity" : 10,
"rate_per_sec": 1
}
```
## Docker
```bash
docker compose up
```

## Примеры использования

### Управление клиентами

#### Создание клиента
```
POST /clients/
Content-Type: application/json

{
  "client_id": "192.168.1.1",
  "capacity": 100,
  "rate_per_sec": 10
}
```

#### Получение информации о клиенте
```
GET /clients/{client_id}
```

#### Обновление параметров клиента
```
PATCH /clients/
Content-Type: application/json

{
  "client_id": "192.168.1.1",
  "capacity": 200,
  "rate_per_sec": 20
}
```

#### Удаление клиента
```
DELETE /clients/{client_id}
```
